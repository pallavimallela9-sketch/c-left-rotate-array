# Left Rotate Array

This program performs a left rotation of an array by one position.

## Features

* Takes array elements from the user
* Moves each element one position to the left
* Moves the first element to the last position
* Displays the rotated array

## Technology Used

* C

## Concepts Used

* Arrays
* For loop
* Array traversal
* Variables

## Sample Output

Enter the number of elements: 5
Enter 5 elements:
10 20 30 40 50
Array after left rotation: 20 30 40 50 10
